## 🛠️ TÍNH NĂNG ĐÃ TRIỂN KHAI HOÀN CHỈNH

1. **Tìm kiếm & Lọc danh mục:**
   - Tìm kiếm thời gian thực theo từ khóa, mã SKU, tên hàng và quy cách ống.
   - Lọc theo 6 danh mục Z121 và lọc theo dịp sử dụng (Tết, Tiệc cưới, Khai trương, Sinh nhật).
2. **Bảng điều khiển 3 cột Master (Desktop) & Sequential Stack (Mobile):**
   - Cột 1: Combo Tết Trọn Gói (Sum Vầy 580k, Đại Cát 990k, Thịnh Vượng 1680k) kèm 1-click chọn combo.
   - Cột 2: Sản phẩm bán chạy nhất kèm bộ chọn số lượng `- 1 +`, nút đặt mua, tim yêu thích, cân so sánh.
   - Cột 3: Video thực tế preview card + 3 thẻ điều hướng an toàn, pháp lý Nghị định 137, FAQ.
3. **Bộ chọn sản phẩm 30 giây (Quick Quiz):**
   - 3 bước: Dịp sử dụng, Không gian địa điểm, Ngân sách -> Gợi ý chính xác và cuộn mượt đến danh mục.
4. **So sánh thông số (Compare Modal):**
   - So sánh đối chiếu tối đa 3 sản phẩm song song: Tầm cao, Thời lượng, Số ống, Màu bao bì, Âm thanh, Giá niêm yết.
5. **Danh sách yêu thích (Favorites Drawer):**
   - Lưu trữ tự động qua `localStorage`, hiển thị số lượng và thêm toàn bộ vào giỏ yêu cầu.
6. **Soi chi tiết bao bì 2.2x (Macro Packaging Inspection):**
   - Kính lúp phóng đại 2.2x trên ảnh chụp thật tại cửa hàng giúp khách hàng kiểm tra rõ chữ in và tem nhãn của Nhà máy Hóa chất 21.
7. **Giỏ yêu cầu tư vấn (Request Cart):**
   - Cơ chế tạo phiếu tư vấn chuẩn `Z121-REQ-XXXX`, sao chép 1-click và gửi trực tiếp qua Zalo / Hotline.
   - Checkbox tự khai độ tuổi 18+ và cam kết quy tắc chèn gạch PCCC.
   - Chọn nhanh khu vực 9 huyện/thành phố tại Cà Mau.
   - Cảnh báo rõ ràng: Không thu tiền online, không giao hàng qua đơn vị chuyển phát cấm.
8. **Responsive & Mobile Bottom Navigation:**
   - Fixed Bottom Bar (Trang chủ, Sản phẩm, Chọn nhanh, Giỏ yêu cầu).
   - Nút nổi CTA liên hệ Zalo & Gọi Chú Bộ Đội tối ưu thao tác ngón cái.

## 🚀 HƯỚNG DẪN CÀI ĐẶT & KHỞI CHẠY

### 1. Yêu cầu môi trường
- Node.js >= 18.18 (đã kiểm thử hoàn hảo trên Node `v24.16.0`).
- Trình quản lý gói `npm`.

### 2. Cài đặt thư viện
```bash
npm install
```

### 3. Khởi chạy môi trường phát triển (Development)
```bash
npm run dev
```
Truy cập: `http://localhost:3000`

### 4. Đóng gói và chạy Production
```bash
npm run build
npm run start
```
Website hỗ trợ proxy qua cổng `3001` (file `proxy.js`):
```bash
node proxy.js
```
